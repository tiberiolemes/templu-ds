Pronto para virar interface

Tokens portáveis e decisões documentadas. Integre a base no projeto que vai consumir o sistema.

A marca é Templu.
A base é shadcn.

O catálogo é estático e sem dependências de execução. Os componentes de produção devem vir do shadcn, preservando seus comportamentos e recursos de acessibilidade.

Guia de integração 
@import "tailwindcss";
/* Preserve o CSS gerado pelo shadcn. */
@import "./design-system/tokens.css";
@import "./design-system/tailwind.css";

/* No componente shadcn */
